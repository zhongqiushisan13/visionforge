VisionForge 1.5.0 beta.3  ·  试用说明
=====================================

这是什么
--------
把一句话做成短剧的工具：写剧本 → 分镜 → 出关键帧 → 出镜头 → 剪辑合成。
这一版的重点是「连续性」和「能自己装环境」：
  - 系列素材库：角色 / 场景 / 道具存在系列层，多集共用
  - 参考图出图：角色定妆图当参考，换场景也不换脸
  - 本地出图环境面板：检测 ComfyUI、缺什么装什么、也支持离线导入

运行条件
--------
  Windows 10 / 11 64 位，建议 16G 内存。
  显卡不是必须：不装 ComfyUI 也能用云端模型，或者用占位片先把流程跑通。

怎么开始
--------
  1. 解压到不含中文和空格的路径，比如 D:\VisionForge
     （路径带中文或空格时，个别组件可能起不来）
  2. 双击 VisionForge.exe，首次启动约 10~20 秒
  3. 到「设置」填 Key：
       DeepSeek  —— 写剧本、分镜需要
       MiniMax   —— 云端出视频需要（可选）
     没有 Key 也能手工建项目、导入自己的素材、剪辑合成。
  4. 回「工作台」新建项目，写一句梗概，点「生成剧本」

本地出图（可选，不装也能用）
----------------------------
  需要单独的 ComfyUI。设置页底部「本地出图环境」面板：
    - 已经装了 ComfyUI：填一下目录就能用，不会重复下载模型
    - 没装：点「安装」，会下 SDXL 底模等约 10GB（装不装不影响其他功能）
    - 有现成模型文件：用「离线导入」直接指过去

数据放在哪
----------
  全部在程序目录里：projects\（项目）、series\（素材库）、logs\（日志）
  整个目录拷走就等于备份或迁移到另一台机器。

已知限制（beta 版）
-------------------
  - 素材库、字幕表、诊断包都是新功能，边角情况可能还有问题
  - 既没有 ComfyUI 也没有云端 Key 时，只能出占位片（纯色+文字），
    用来验证流程，不是真实画面
  - 人脸一致性靠参考图，是「很像」不是「就是同一个人」

遇到问题怎么反馈
----------------
  设置页最下面「诊断与备份 → 导出诊断包」，把生成的 zip 发回来就行。
  里面已经自动去掉了 API Key、用户名和项目内容，可以直接传。

  另外：如果出现「保存没反应 / 一直提示未授权」，先看任务管理器里
  是不是开了两个 VisionForge.exe，关掉多余的再试。
