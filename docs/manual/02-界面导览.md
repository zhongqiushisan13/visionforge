# 02 界面导览

侧边栏六个页面，对应生产流程从左到右。左上角是项目名，左下角是工作目录。

## 工作台

整条流水线的总控台。

| 区域 | 内容 |
|---|---|
| 顶部 KPI | 镜头数、总时长、成片状态、预估耗时 |
| 流水线卡片 | 剧本 / 关键帧 / 镜头 / 配音 / 合成，每张卡显示进度与「单步执行」按钮 |
| 一键成片 | 从当前状态继续跑到出片，已完成的部分不重做 |
| 最近项目 | 点开切换工程 |

常用按钮：

- **新建项目**：填需求、时长、画幅、镜头数，可选 MOCK
- **一键成片**：整片跑一遍
- **单步执行**：只跑某一步，调试时用

## 剧本

看模型理解成了什么。

- 上半部分是 logline、风格、人物、幕结构（beat）
- 下半部分是分镜表：镜头号、时长、画面描述、台词
- 可以直接改文字，点「保存剧本」写回工程

改完分镜表后**不会自动重拍镜头**，需要去分镜页对具体镜头点「重拍」。

## 分镜

以卡片网格展示每条镜头。

每张卡显示：缩略图（首帧或视频）、状态标签（待生成 / 已出图 / 已出片 / 失败 / 停用）、时长、台词摘要。

卡片上的操作：预览、重拍、换素材、启用/停用、删除。

## 手动剪辑（时间线）

真正的精修页，左边轨道、右边检查器。

**时间线区**

- 卡片按顺序横排，宽度按时长比例
- 拖拽排序；点选后右侧出检查器
- 卡片上标出倍速、转场名，方便一眼看出哪里被改过
- 顶部有 AI 指令输入框

**检查器分组**

| 分组 | 可改什么 |
|---|---|
| 片段 | 时长 1~15 s、入点 trim、启用、分割（第 N 秒切成两条） |
| 变速 | 0.25x~4x，快捷档 0.5/0.75/1/1.25/1.5/2，倒放、镜像 |
| 转场 | 11 种（硬切/淡入淡出/叠化/左划/右划/上滑/下滑/放大推入/黑场/白闪/圆形展开），时长 0.1~1 s |
| 调色 | 7 个预设 + 亮度/对比度/饱和度/色温 |
| 文字层 | 标题文字、位置（顶/中/底）、字号，与对白字幕分层 |
| 声音 | 单镜音量 0~200% |
| 提示词 | 视频 / 关键帧提示词，微调后重拍更准 |

改完点「保存」，然后回工作台点「用当前剪辑合成」。

## 成片

- 在线播放器（成片生成后出现）
- 下载 MP4 / 下载 SRT
- 交付信息：时长、体积、分辨率、镜头数、转场数
- BGM 上传（会自动压到 18% 并在结尾淡出）
- 任务日志（最近 12 条，出问题先看这里）

## 设置

分左右两栏。

**左栏：模型与接口**

- 剧本大脑：来源（自动 / 云端 / 本地）、Base URL、模型名、API Key
- 视频生成：模式（auto / cloud / local / comfyui / mock）、Base URL、模型名、分辨率、Key、提交/查询路径、ComfyUI 工作流
- 「测通道」按钮：实际打一次接口，告诉你通不通
- 关键帧：ComfyUI 地址、工作流文件、默认 LoRA 与权重

**右栏：系统与渲染**

- 系统自检：CPU/内存/显卡/编码器/字体/WebView2/ComfyUI 状态，可一键重新检测
- 成片规格：宽高、帧率、编码器、字幕字号与字体、是否烧录字幕
- MOCK 开关
- 运行环境：工作目录、ffmpeg 路径、版本号

改完点「保存设置」，会写进 exe 同级的 `.env`。

## 快捷键与交互细节

| 操作 | 效果 |
|---|---|
| 点时间线卡片 | 选中并打开检查器 |
| 滑块拖动 | 实时显示数值，但**要保存才生效** |
| 任务面板 | 右下角浮层，进度条 + 最近 3 条日志 |
| 提示条（toast） | 右下角，成功绿色、警告黄色、失败红色 |

> 注意：滑块只改界面值，「保存」才写回 `project.json`。改完不点保存然后抱怨没生效，是最高频的误操作。
