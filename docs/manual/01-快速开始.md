# 01 快速开始

## 一、拿到程序

两种方式，选一种：

| 方式 | 适合 | 命令/操作 |
|---|---|---|
| 下载 Release（推荐） | 只想用 | 打开 [Releases](https://github.com/zhongqiushisan13/visionforge/releases)，下最新 `VisionForge-v1.1.2-win64.zip`，并核对同页 `SHA256SUMS.txt` |
| 从源码运行 | 想改代码 | 见下方「源码启动」 |

解压后目录长这样：

```
VisionForge/
├── VisionForge.exe          ← 双击这个
├── _internal/               ← 运行时 + 内置 ffmpeg，别动
├── .env.example             ← 参考模板；真正生效的 Key 默认写到用户目录
├── config.example.json
├── examples/                ← 示例 brief
├── projects/                ← 你的工程会生在这里
├── logs/runtime.log         ← 出问题先看这个
└── README.md
```

> 解压位置：桌面、`D:\VisionForge`、用户目录都行。**别放 `C:\Program Files`**，那里没有写权限，配置和成片会写不进去。

## 二、第一次启动

双击 `VisionForge.exe`。首次启动会先做一次环境体检（约 3~5 秒），然后弹出窗口，同时在 exe 同级生成 `config.json`；日志会告诉你 API Key 配置文件的位置（Windows 默认是 `%APPDATA%\VisionForge\.env`，不会随便携包被拷走）。

体检会自动决定这些参数：

- 视频编码器（NVENC / QSV / AMF / libx264）——**会真跑一帧试编码**，不是看列表
- 输出分辨率——内存小于 8 GB 自动降到 1280×720
- 并发数、中文字幕字体、ComfyUI 出图尺寸

想重跑体检：设置页 → 系统自检 → 「重新检测并应用」。

## 三、跑出第一条片子

1. 工作台点 **新建项目**
2. 填一句话需求，例如「雨夜便利店，店员与常客的无声默契」
3. 时长选 30~60 秒（第一次别贪长）
4. **勾上 MOCK 模式**（没配 Key 时默认已勾）
5. 点 **一键成片**

流程会依次执行：剧本 → 分镜 → 关键帧 → 镜头 → 配音 → 合成。右下角进度面板能看到每一步。

跑完去 **成片** 页：在线播放、下载 MP4、下载 SRT 字幕。

## 四、第一次改片子

进 **时间线** 页：

- 拖拽卡片改顺序
- 点卡片选中，右侧检查器改字幕、时长、转场、变速、调色
- 改完点「用当前剪辑合成」

改字幕不会重算镜头（缓存按指纹命中），通常几十秒就能出结果。

## 五、源码启动（开发者）

```bash
git clone https://github.com/zhongqiushisan13/visionforge.git
cd visionforge
python -m pip install -r requirements.txt
python run_app.py            # 桌面窗口
# 或只起服务： python -m uvicorn videoforge.web.server:app --port 8765
```

要求 Python 3.10+。ffmpeg 不用装，`imageio-ffmpeg` 自带静态版（需含 libass / libx264，本项目会自检）。

Windows 下也可以直接双击 `启动VisionForge.bat`。

## 六、命令行参数

```
python run_app.py                  # 默认：桌面窗口，端口 8765
python run_app.py --serve          # 只起 HTTP 服务，不开窗
python run_app.py --serve --port 9000
python run_app.py --browser        # 强制用系统浏览器
python run_app.py --no-autoconfig  # 跳过首次自动配置
```

exe 同样支持这些参数：

```
VisionForge.exe --serve --port 8790
```
