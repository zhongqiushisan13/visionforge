# 04 剪辑手册

时间线页是唯一需要学的地方，其余页面都是「看」和「点一下」。

## 一、基本操作

| 想做什么 | 怎么做 |
|---|---|
| 换顺序 | 拖拽卡片到目标位置 |
| 删掉一条 | 选中 → 检查器底部「删除」 |
| 保留但不进成片 | 取消勾选「进成片」 |
| 只要前半段 | 调「入点 trim」 |
| 加长/缩短 | 调「时长」，1~15 s |
| 从中间切开 | 填「分割位置（秒）」→ 点「分割」 |
| 换素材 | 「换素材」上传本地视频 |
| 追加素材 | 顶部「导入素材」 |

**顺序很重要**：改完点「保存」，再回工作台点「用当前剪辑合成」。只保存不合成的，成片还是旧的。

## 二、变速

- 范围 0.25x ~ 4x
- 快捷档：0.5 / 0.75 / 1 / 1.25 / 1.5 / 2
- 倒放、镜像在旁边两个勾选框

变速会改变实际时长：`新时长 = 原时长 ÷ 倍速`。所以 2x 的 6 秒镜头只占 3 秒。时间线卡片宽度会跟着变。

**音画同步**：变速只作用于画面，配音保持原速。台词密集的镜头别调太快，否则会明显对不上。

## 三、转场

11 种，全部是 ffmpeg `xfade` 的真实转场：

| 名称 | 适合 |
|---|---|
| 硬切 | 同场景内快节奏 |
| 淡入淡出 | 时间跳跃、段落结束 |
| 叠化 | 最通用，情绪过渡 |
| 左划 / 右划 / 上滑 / 下滑 | 方向性移动，配合运镜 |
| 放大推入 | 强调、进入细节 |
| 黑场过渡 | 章节分隔 |
| 白闪 | 回忆、闪光、快切 |
| 圆形展开 | 趣味、开场 |

转场时长 0.1~1 s，默认 0.4 s。相邻两条都要设——转场记在**后一条**镜头上（`S02` 的转场是 S01→S02 的衔接）。

注意：转场会让总时长变短（重叠部分被吃掉）。10 条 6 秒镜头 + 9 个 0.4 秒转场 = 60 - 3.6 = 56.4 秒。

## 四、调色

7 个预设：原片 / 电影青橙 / 黑白 / 复古胶片 / 冷调 / 暖调 / 高饱和。

选完预设还能微调四项：

| 参数 | 范围 | 直觉 |
|---|---|---|
| 亮度 | -1 ~ 1 | 整体明暗 |
| 对比度 | 0.5 ~ 2 | 反差强弱 |
| 饱和度 | 0 ~ 2 | 0 是黑白，1 是原样 |
| 色温 | -1 ~ 1 | 负值偏冷（蓝），正值偏暖（橙） |

**别过度**：亮度 +0.2、对比 +1.1 已经很明显了。一次调太多，画面会显得脏。

## 五、文字层

每条镜头可以叠一个独立标题，和对白字幕分开渲染，不会互相挤掉。

- 位置：顶部 / 居中 / 底部
- 字号：留 0 用全局默认
- 内容：任意文字，支持中文

用法建议：标题只放在关键镜头（开场、转折、结尾），每条都放会像 PPT。

字幕和标题同时出现在底部时会重叠，所以标题放底部时请把字幕位置当心——或者干脆用顶部。

## 六、声音

| 项 | 说明 |
|---|---|
| 单镜音量 | 0~200%，默认 100% |
| BGM | 成片页上传，自动压到 18% 并淡出 |
| 响度归一 | 合成时自动 `loudnorm` 到 -16 LUFS，不用手动调 |

单镜音量适合压环境音、突出独白。BGM 想更响就改 `config.json` 里的 `bgm_volume`（0.18 是默认）。

## 七、AI 指令

时间线顶部输入框，用一句话改参数。例：

```
全部镜头调成黑白
第 2 镜 1.5 倍速
第 1 镜加叠化转场
全部加电影青橙，第 3 镜和第 5 镜 0.75 倍速
```

规则：

- 说「全部 / 所有 / 整片」→ 作用于全部镜头
- 说「第 2 镜 / S02」→ 只改那一条
- 可以一句话里下多个指令，用逗号分隔

配置了 LLM 时由模型解析；没有 LLM 时走本地正则规则，常见说法也能识别。解析结果会以「已应用」提示，并在时间线卡片上立刻可见。

**注意**：AI 指令改的是参数，不会自动合成。改完仍需点「用当前剪辑合成」。

## 八、重拍单镜

不满意某条镜头时，不要整片重跑：

1. 选中那条
2. 点「重拍」，写一句意见，例如「雨更大一些，镜头再低一点」
3. 确认

系统会改写中英文提示词、换随机种子，只重做这一条。其余镜头与配音不受影响。

## 九、常见误区

| 误区 | 实际 |
|---|---|
| 改字幕要等十分钟 | 不用。字幕不进镜头缓存，只重跑合成 |
| 停用镜头会删文件 | 不会。文件保留，只是不进成片 |
| 转场越花越好 | 商业片 90% 是硬切和叠化 |
| 调色预设越重越好 | 预设是起点，成品通常还要往回收一点 |
| 分割后原镜头变短 | 两条加起来等于原时长，入点自动换算 |
