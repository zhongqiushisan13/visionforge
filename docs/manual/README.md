## 三十秒上手

1. 下载 `VisionForge-v1.1.0-win64.zip`，解压到**有写权限的目录**（不要放 `C:\Program Files`）
2. 双击 `VisionForge.exe`，等 3~5 秒自动体检
3. 工作台点「新建项目」，写一句需求，勾上 **MOCK 模式**
4. 点「一键成片」，等进度条走完
5. 成片页播放、下载；想改就去时间线页

MOCK 模式产出的是占位画面（渐变色块），用来确认流程和字幕是否正常。要真画面，去 [03 模型配置](03-模型配置.md)。

## 三条铁律

1. **不要解压到 `C:\Program Files`** —— 程序把 `config.json`、`projects/`、`logs/` 写在 exe 同级，那里没写权限。
2. **exe 未签名**，SmartScreen 会拦一下：点「更多信息 → 仍要运行」。
3. **没有 Key 时默认 MOCK**，它不会假装在调模型，也不会偷偷花钱。
