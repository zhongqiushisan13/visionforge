# 03 模型配置

VisionForge 有四个能力槽：**剧本（LLM）**、**关键帧（图像）**、**镜头（视频）**、**配音（TTS）**。每个槽都能独立选云端或本地，互不绑定。

配置改完点「保存设置」，写入 exe 同级的 `.env`。改完需要重启应用才完全生效（服务端缓存了配置）。

## 一、判断当前状态

设置页右上角「系统自检」会列出：

- 剧本大脑：云端就绪 / 本地 / 未配置
- 镜头来源：当前模式与地址
- ComfyUI：在线 / 未连接
- 编码器：实际可用列表

点「测通道」会真发一次请求，比看配置项靠谱。

## 二、剧本（LLM）

任何 OpenAI 兼容接口都能用，因为只依赖 `/chat/completions` 和 `response_format={"type":"json_object"}`。

### 云端（DeepSeek）

```env
DEEPSEEK_MODE=cloud
DEEPSEEK_API_KEY=sk-xxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

### 本地（Ollama 为例）

```bash
ollama pull qwen2.5:14b
```

```env
DEEPSEEK_MODE=local
DEEPSEEK_BASE_URL=http://127.0.0.1:11434/v1
DEEPSEEK_MODEL=qwen2.5:14b
# API Key 留空即可
```

本地服务不校验 Key 时不要填假值——代码只在有 Key 时才带 `Authorization` 头。

### 模型不支持 JSON 模式怎么办

不用管。客户端有三层兜底：JSON 模式 → 从自由文本里扫平衡括号抽 JSON → 换备用模型 → 最后用内置示例分镜。会慢一点，但不会卡死。

## 三、关键帧（ComfyUI）

```env
COMFYUI_BASE_URL=http://127.0.0.1:8188
COMFYUI_WORKFLOW=txt2img_api.json
COMFYUI_DEFAULT_LORA=style_v3.safetensors
COMFYUI_LORA_STRENGTH=0.75
```

工作流文件放在 `workflows/` 下（打包版在 `_internal/workflows/`，也可以在 exe 同级建 `workflows/` 覆盖）。

**LoRA 不用手改工作流**：程序会遍历节点图，找到 checkpoint 加载节点，插入一个 `LoraLoader`，把它所有下游消费者重定向过去。你原来的工作流不需要动。

节点识别规则：

| 用途 | 识别方式 |
|---|---|
| 正向提示词 | 节点标题含 `POSITIVE` / `positive` |
| 负向提示词 | 标题含 `NEGATIVE` |
| 分辨率 | 节点输入里有 `width` + `height` |
| 采样器 | 类名 `KSampler` / `KSamplerAdvanced` |

设置页点「检测」会读回 ComfyUI 的 checkpoint 与 LoRA 列表，点一下就填进输入框。

## 四、镜头（视频）

四种模式，按需选：

### 1. 云端 MiniMax H3

```env
MINIMAX_MODE=cloud
MINIMAX_API_KEY=xxxxx
MINIMAX_VIDEO_MODEL=MiniMax-H3
MINIMAX_RESOLUTION=768P
MINIMAX_RATIO=16:9
```

流程是异步任务：提交拿 `task_id` → 轮询状态 → 下载结果。错误码会被翻译成中文提示（限额、内容审核、参数错误等）。

### 2. 本地兼容网关（免 Key）

只要你的服务实现两个接口：

```http
POST {base}/v2/video_generation
{ "model": "MiniMax-H3",
  "content": [{"type":"text","text":"..."},
              {"type":"image_url","image_url":{"url":"data:image/png;base64,..."},"role":"first_frame"}],
  "duration": 6, "resolution": "768P", "ratio": "16:9" }
→ { "task_id": "xxx" }

GET {base}/v2/query/video_generation/{task_id}
→ { "task": { "status": "succeeded", "content": { "url": "http://.../out.mp4" } } }
```

```env
MINIMAX_MODE=local
MINIMAX_BASE_URL=http://127.0.0.1:8000
```

协议形状不一样也没关系，设置页可以改提交/查询路径。想先验证连通性，仓库里有 mock 服务：

```bash
python tools/mock_h3_server.py --port 8798 --video 某个现成mp4
MINIMAX_MODE=local MINIMAX_BASE_URL=http://127.0.0.1:8798 python run_app.py
```

### 3. ComfyUI 视频工作流

```env
MINIMAX_MODE=comfyui
MINIMAX_VIDEO_WORKFLOW=wan21_i2v.json
MINIMAX_VIDEO_TIMEOUT=3600
```

工作流的节点标题按这套约定写，适配器才找得到：

| 标题 | 作用 |
|---|---|
| `POSITIVE` / `NEGATIVE` | 提示词 |
| `LOAD_IMAGE` | 首帧图（会自动上传） |
| 含 `width` + `height` | 分辨率 |
| 含 `length` / `num_frames` / `video_frames` | 帧数 = 时长 × fps |
| 输出节点 `SaveVideo` / `VHS_VideoCombine` | 产物（`gifs` 里的 mp4 也认） |

### 4. 占位（mock）

`MINIMAX_MODE=mock` 或全局 `VF_MOCK=1`。用 ffmpeg 生成渐变色片段，用于验证流程，**不是真画面**。

## 五、配音（TTS）

三级兜底，不需要单独配置：

1. MiniMax T2A（有 `MINIMAX_API_KEY` 时优先）
2. edge-tts（免费，需要联网）
3. 静音轨（离线兜底，保证时间轴闭合）

音色在设置页改 `voice_id`。edge-tts 走系统联网，不需要 Key。

## 六、推荐组合

| 场景 | 剧本 | 关键帧 | 镜头 | 配音 |
|---|---|---|---|---|
| 零成本试跑 | 示例分镜 | 占位图 | 占位片 | 静音 |
| 预算优先 | Ollama | ComfyUI | ComfyUI 视频 | edge-tts |
| 质量优先 | DeepSeek | ComfyUI + LoRA | MiniMax H3 | MiniMax T2A |
| 隐私优先 | 本地 LLM | 本地 ComfyUI | 本地网关 | edge-tts（仅语音外发） |

注意 edge-tts 会把台词发到微软服务器，纯离线场景请用静音或本地 TTS 替换。
