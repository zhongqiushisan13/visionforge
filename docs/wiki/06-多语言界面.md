# 多语言界面

> 界面支持 9 种语言，但**剧本、分镜、字幕不会被翻译**——它们是你创作的内容，语言由提示词决定。

## 操作

### 切换语言

侧边栏底部「地球」图标下拉选择，立即生效，下次启动沿用。

首次启动按系统语言自动匹配：

- `zh-TW` / `zh-HK` / `zh-Hant` → 繁體中文
- 其他 `zh-*` → 简体中文
- `en` / `fr` / `de` / `ja` / `ko` / `es` / `ar` → 对应语言
- 匹配不到 → 英文

### 临时看某语言（不改设置）

```
http://127.0.0.1:8765/?lang=ja
```

适合截图、录屏、给同事演示。参数只对当次页面生效，不写回本地。

### 支持的语言

| 代码 | 语言 | 布局 |
|---|---|---|
| `zh-CN` | 简体中文（源语言） | 左到右 |
| `zh-TW` | 繁體中文 | 左到右 |
| `en` | English | 左到右 |
| `fr` | Français | 左到右 |
| `de` | Deutsch | 左到右 |
| `ja` | 日本語 | 左到右 |
| `ko` | 한국어 | 左到右 |
| `es` | Español | 左到右 |
| `ar` | العربية | 文本右到左，外壳左到右 |

### 深链

```
http://127.0.0.1:8765/#settings
http://127.0.0.1:8765/?lang=en#settings
```

`#settings` / `#timeline` / `#storyboard` / `#export` / `#script` 可直接跳到对应页面。

## 给译者：怎么加一门语言

### 1. 复制词库

```
videoforge/web/static/i18n/en.json  →  xx.json
```

### 2. 翻译值，不要改 key

key 是中文原文，值才是译文。例如：

```json
"保存设置": "Save settings",
"{n} 镜": "{n} shots"
```

`{n}`、`{sec}`、`{label}`、`{hint}` 这些占位符必须原样保留，位置可以按语法调整。

### 3. 注册语言

编辑 `videoforge/web/static/i18n.js`，在 `LANGS` 数组里加一条：

```js
{ id: 'it', name: 'Italiano', html: 'it' },
```

### 4. 跑测试

```bash
python -m pytest -q tests/test_i18n.py
```

它会检查：词条数量是否一致、有没有空翻译、占位符有没有丢。

### 5. 自测

`?lang=it` 打开，重点看设置页、时间线检查器、弹窗——这三处文案最密。

## 原理（为什么这样实现）

### 为什么用中文原文当 key

常见做法是 `settings.save.title` 这种语义 key，需要额外维护一层映射。直接用源语言文本当 key（gettext 风格）有两个好处：

1. 代码里写 `t('保存设置')` 一眼知道是什么
2. 漏翻时自动回退中文，不会出现 `settings.save.title` 这种裸 key

代价是改中文原文会同时让所有语言的这条失效——所以中文文案一旦定稿就尽量别动。

### 为什么是「渲染后替换文本」

前端是原生 JS + 模板字符串，没有构建步骤，也就没有编译期提取文案的环节。做法是：渲染完 DOM 后遍历文本节点，命中词库就替换，命不中保留原文。

好处是不用给每个模板加标记；代价是**被标签切开的句子匹配不到**。所以带 `<span>` 的句子要写成整句 `t('...')`，或者拆成几个短键。

### 为什么阿拉伯语只让「文本」右到左

阿拉伯语从右往左读，所以文字方向必须是 RTL；但如果把整个 `<html dir="rtl">`，flex 布局会整体镜像：侧边栏跑到右边、时间线从右往左排、进度条反向。对剪辑工具来说这是灾难——时间轴的方向感比语言习惯更重要。

所以这里的取舍是：

- 文本块（段落、标题、标签、说明）单独 `direction: rtl; text-align: right`
- 外壳（侧边栏、工具栏、时间线、检查器）保持 LTR
- 数字、时长、模型名用 `unicode-bidi: isolate` 隔离，避免出现「8 / 8」被拼成「/ 8 8」这类双向文本错乱

### 为什么繁体不是逐字转换

「视频 → 視頻」是逐字转换的结果，台湾实际写「影片」；「设置 → 設置」应为「設定」；「文件 → 文件」应为「檔案」。所以繁中词库用 OpenCC 的 `s2twp` 做**词级**转换，再人工校对专有名词。

### 为什么切换语言要整页刷新

已经渲染的 DOM 里混着用户数据（项目名、台词），只重跑渲染函数容易留下半翻状态。整页刷新最稳，代价是几百毫秒。

## 常见问题

**切了语言但个别词还是中文**：那条文案是拼接出来的（含变量或跨标签），没有被词库命中。属于已知边界，可以在仓库提 issue 指出具体位置。

**Arabic 里数字和中文混排有点怪**：这是双向文本的正常现象，程序已把数字隔离为 LTR；混排的项目内容仍按各自语言方向显示。

**想只让界面英文、剧本中文**：可以。界面语言和创作语言是两件事，剧本语言由你在需求里写的语种决定。
