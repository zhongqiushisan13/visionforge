# 从一句话到成片

> 主流程只有七步。每步都能单独重跑，失败不会毁掉前面已经做好的部分。

## 操作

### 第 1 步：新建项目

顶栏「新建项目」，填四样东西：

| 字段 | 说明 | 建议 |
|---|---|---|
| 需求 | 一句话说清「给谁、做什么、什么调性」 | 至少一句完整的话，越具体越好 |
| 时长 | 30 / 60 / 90 / 120 秒 | 60 秒 ≈ 8~12 个镜头 |
| 画幅 | 16:9 / 9:16 / 1:1 | 竖屏适合短视频 |
| 影像风格 | 电影感 35mm / 品牌广告 / 纪录片手持 / 赛博霓虹 / 国风水墨 | 会拼进每条镜头的提示词 |

第一次建议勾上 **MOCK 模式**：不花钱，用占位素材把流程走一遍，确认界面和导出没问题。

点「开始创作」后，右下方任务浮窗会显示进度和日志。

### 第 2 步：看剧本

「剧本」页能改：片名、一句话故事、故事梗概、影像风格。

右侧是 AI 拆出来的**节拍**（每段情绪与时长）和**人物**（外形描述，含英文版）。人物的 `look_en` 会被拼进镜头提示词，保证同一角色前后长得像。

改完点「保存剧本」。**改剧本不会自动重跑分镜**——分镜是生成时定下的，要改镜头请去分镜页。

### 第 3 步：检查分镜

「分镜」页每张卡是一个镜头，含首帧、时长、运镜、台词、状态。

看到不合适的可以：

- **重拍**：写一句意见（「雨再大一点，镜头推近慢些」），AI 改写提示词后只重跑这一镜
- **编辑**：进右侧检查器，改时长、提示词、字幕、转场
- **停用**：不进成片，但文件保留

### 第 4 步：出关键帧

工具栏「出关键帧」。每镜生成一张首帧图，存 `keyframes/`。

没有配 ComfyUI 时会用本地占位图（渐变 + 提示词），流程照样能往下走。

### 第 5 步：生成镜头

工具栏「生成镜头」。按配置走云端 H3、本地网关或 ComfyUI 工作流。

- 单镜 4~15 秒，超了会被截断
- 失败的镜头会标红，日志里有原因
- 一镜失败不影响其他镜

### 第 6 步：配音

工具栏「生成配音」。

顺序上**配音在镜头之前**：配音出来后会拿到真实音频时长，再回写镜头时长（`audio_duration + 0.45s`，夹在 4~15 秒），避免「话没说完画面就切了」。

有 MiniMax Key 用 speech T2A；没有就用 edge-tts；再不行静音兜底。

### 第 7 步：剪辑与导出

「手动剪辑」页确认顺序与节奏 →「成片」页点「合成成片」。

导出会做四件事：统一分辨率帧率 → 拼接（含转场）→ 混音（配音 + BGM + 响度归一）→ 烧字幕并生成 SRT。

完成后可下载 MP4 和 SRT，也能看到成本小结。

## 原理（为什么这样排）

### 为什么是「两段式」编剧

一次让模型写完整剧本 + 分镜，它容易在长输出里丢设定。拆成两段：

1. 先出大纲：标题、logline、梗概、节拍、人物
2. 再把大纲展开成分镜表：每镜的场景、运镜、台词、英文提示词

第二段只盯「怎么拍」，上下文更聚焦，镜头描述也更稳定。两段之间都会做 JSON 校验，不合法就回锅重修。

### 为什么镜头状态要分这么细

`pending → keyframe → rendered → voiced`，加上 `failed` / `skipped`。

有了状态，才能做到：

- 断点续跑：重开只补没做完的
- 单镜重拍：只影响这一镜，不动其他
- 增量渲染：加一镜不用全片重跑
- 精确计费：每次付费调用都记在 `meta.costs`

### 为什么配音要抢在镜头前面

视频模型按「秒」出片，配音按「字」生成，两者天然不齐。先配音拿到真实时长，再回调镜头时长，是成本最低的对齐方式；反过来做只能靠拉伸音频或砍画面。

### 为什么失败要分「可重试」和「不可重试」

- 限流、超时、5xx：可重试，指数退避（2s、4s、8s）
- 鉴权失败、模型不存在、敏感词：不可重试，直接报错并说明原因

分不清这两类，就会出现「明明 Key 错了却重试半小时」的浪费。

### 降级链是怎么走的

```
剧本：云端模型 → 本地 Ollama → 内置示例分镜
镜头：云端 H3 → 本地网关 → ComfyUI 工作流 → 占位片
配音：MiniMax T2A → edge-tts → 静音
关键帧：ComfyUI → 本地占位图
```

任何一环没配好都能出片，只是质量下降。想强制走某条，在设置里把模式从 `auto` 改成 `cloud` / `local` / `comfyui` / `mock`。

### 一键成片到底做了什么

按依赖顺序串起来：`plan → keyframes → voice → clips → assemble`。已经完成的步骤会跳过（除非勾了强制重跑），所以第二次点只会补缺的部分。

## 节奏建议

| 片长 | 镜头数 | 单镜时长 | 备注 |
|---|---|---|---|
| 30s | 5~7 | 4~6s | 单镜别超过 8s，容易走形 |
| 60s | 8~12 | 5~7s | 最稳的区间 |
| 90s | 12~16 | 6~8s | 建议分两幕 |
| 120s | 16~22 | 6~9s | 必须有明确节拍，否则会散 |

一句话原则：**一镜只做一件事**。想让人物「先说台词再转身再推近」，拆成两镜更稳。
