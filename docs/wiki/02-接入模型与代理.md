# 接入模型与代理

> 编剧模型决定「剧本好不好看」，它和镜头模型是两条独立的通道：换编剧不用动镜头，反之亦然。

## 操作

### 1. 在设置页接入（推荐）

「设置 → 模型与接口 → 剧本大脑 · 多厂商」：

1. **厂商**：下拉选一家
2. **Base URL / 模型**：选厂商后自动填默认值，模型可改可手输
3. **API Key**：填一次即可，之后留空表示不修改
4. **测通道**：用当前表单里*还没保存*的值发一次极小的真实请求
5. 通过后点「保存设置」

「测通道」返回 `401` 说明网络通了、Key 不对；返回超时才可能是代理或网络问题。

### 2. 直接用环境变量

编辑 `%APPDATA%\VisionForge\.env`：

```bash
LLM_PROVIDER=anthropic
LLM_MODEL=claude-sonnet-4-5
LLM_API_KEY=sk-ant-xxxx
LLM_MODE=auto
```

`LLM_MODE` 取值：

- `auto`：有 Key 走云；没有 Key 但 Base URL 是本机，就走本地
- `cloud`：强制云端
- `local`：强制本地（Ollama / vLLM / LM Studio）
- `mock`：不用模型，走内置示例分镜

老的 `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` / `DEEPSEEK_BASE_URL` 继续生效，从 1.1.x 升上来的安装不用改。

### 3. 内置的 11 个通道

| 厂商 | 协议 | 默认地址 | 适合 |
|---|---|---|---|
| DeepSeek | OpenAI 兼容 | `api.deepseek.com` | 中文剧本稳、便宜 |

### 4. Key 存在哪

- 文件：`%APPDATA%\VisionForge\.env`（POSIX 下 `~/.config/visionforge/.env`）
- 每家一个槽位：`LLM_KEY_OPENAI`、`LLM_KEY_ANTHROPIC`……切回某家时自动取它自己的 Key
- 界面只显示 `sk-abc…xyz` 掩码，永远不回传明文

想把 Key 交给别人协作？**别传 .env**，让对方自己填。

## 原理（为什么这样设计）

### 为什么用「协议」而不是「厂商」来划分代码

11 家厂商其实只有三种请求格式：

| | OpenAI 兼容 | Claude | Gemini |
|---|---|---|---|
| 路径 | `/chat/completions` | `/v1/messages` | `/models/{模型}:generateContent` |
| 鉴权 | `Authorization: Bearer` | `x-api-key` + `anthropic-version` | `x-goog-api-key` |
| system 放哪 | `messages[0]` | 独立 `system` 字段 | `systemInstruction` |
| JSON 模式 | `response_format` | 没有，靠提示词 | `responseMimeType` |

所以代码里只写三套组装逻辑，厂商差异全部收进注册表。新增一家 = 加一条记录，业务层不用改。

### 为什么「测通道」要用真实请求

很多错误只有发出去才暴露：Key 没该模型权限、区域限制、余额不足、服务端 429。本地校验只能证明格式对，证明不了能跑通。测通道用的是最小请求（一句「只回答两个字」），花费可以忽略。

### 请求到底走哪条路

```
界面 → 127.0.0.1:8765（本地 FastAPI，带 token）
     → 后端 requests
     → DNS → TCP 443 → TLS → HTTP POST
     → （可选）你的系统代理 127.0.0.1:7897
     → 厂商边缘节点
```

三个要点：

1. **没有中转服务器**。VisionForge 不是 SaaS，你的请求直接从本机到厂商。
2. **云端跟随系统代理**。程序读 `HTTP(S)_PROXY` 或 Windows 注册表里的代理设置；你换梯子节点，程序不用改。
3. **本地模型强制绕过代理**。`127.0.0.1:11434` 这类地址如果被塞进代理，会得到 502。程序会按 Base URL 自动判断，本机地址一律直连。

### 代理只看得见域名

HTTPS 下代理走 `CONNECT 域名:443` 隧道，正文是端到端加密的，代理看不到你写了什么剧本。除非代理装了自签根证书做中间人解密——那种情况程序会因证书不匹配直接报错，不会静默降级。

### 401 / 403 / 404 / 429 分别代表什么

| 状态 | 含义 | 该查什么 |
|---|---|---|
| 401 | 到了厂商，身份不认 | Key 是否复制全、是否过期 |
| 403 | 身份认了但没权限 | 账号是否开通该模型、是否欠费 |
| 404 + `model not found` | 通了，模型名不对 | 模型 ID 拼写、是否下线 |
| 429 | 到了，被限流 | 等一会；程序会自动退避重试 3 次 |
| 000 / 超时 | 没到厂商 | 代理/节点、DNS、防火墙 |
| 502 `CONNECT tunnel failed` | 代理拒绝转发 | 代理规则里放行该域名 |

### 为什么思考型模型容易「返回空文本」

qwen3、deepseek-reasoner 这类模型会先输出一段 `reasoning`，再给正文。如果 `max_tokens` 太小，预算全被思考吃掉，正文就是空的。v1.2.2 起：测通道用 512 token，并在这种情况下明确提示「只返回了思考内容」。

## 常见问题

**切了厂商但请求还用旧 Key？** 保存时会写 `LLM_PROVIDER` 并切换 `LLM_API_KEY`；如果没填新 Key，会取该厂商自己的槽位，取不到就置空，不会拿上一家的 Key 去请求。

**OpenRouter 很慢？** 它要在服务端二次转发，延迟天然高。介意就直连原厂。

**想用公司内网网关？** 厂商选「自定义」，Base URL 填网关地址，模型名按网关文档填；协议默认 OpenAI 兼容。
