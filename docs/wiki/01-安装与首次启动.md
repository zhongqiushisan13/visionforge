# 安装与首次启动

## 操作

### 1. 拿到程序

两种方式，选一个：

- **便携包（推荐）**：从 [Releases](https://github.com/zhongqiushisan13/visionforge/releases) 下载 `VisionForge-vX.Y.Z-win64.zip`，解压到任意目录（例如 `D:\VisionForge`）。不需要装 Python。
- **源码**：`git clone` 后 `pip install -r requirements.txt`，启动用 `python run_app.py`。

解压后先核对校验值：

```powershell
certutil -hashfile VisionForge-v1.2.2-win64.zip SHA256
```

和 Release 页的 `SHA256SUMS.txt` 对得上再用。

### 2. 双击启动

- 双击 `VisionForge.exe` 会打开桌面窗口（基于 WebView2）。
- 想要浏览器版：`VisionForge.exe --browser`。
- 只想起服务、不开窗口：`VisionForge.exe --serve --port 8765`。

默认端口从 `8765` 开始找空闲的（8765 → 8766 → 8767 → 随机）。想固定就加 `--port`。

### 3. 首次启动会自动做三件事

1. 探测硬件：CPU 核数、内存、显卡与显存
2. 选编码器：`h264_nvenc` / `h264_qsv` / `h264_amf` / `libx264` 中挑一个能用的
3. 定默认分辨率与并发数，写进 `config.json`

界面右下角「设置 → 系统自检」能复查这些值；换机器后点「重新检测并应用」。

### 4. 认识三个目录

| 位置 | 放什么 | 能不能删 |
|---|---|---|
| `D:\VisionForge\` | 程序本体、`_internal`、`workflows` | 升级时整体替换 |
| `%APPDATA%\VisionForge\.env` | API Key、模型选择、渲染参数 | **不要随包拷给别人** |
| `D:\VisionForge\projects\` | 每个项目一个文件夹 | 要删就整项目删 |

单个项目内部：

```
projects/我的片子/
├─ project.json      # 剧本、分镜、状态、成本，全在这
├─ keyframes/        # 每镜首帧
├─ clips/            # 每镜视频
├─ audio/            # 配音
├─ cache/            # 中间产物
├─ output/           # 成片 mp4、字幕 srt
└─ logs/
```

### 5. 升级与回滚

升级：关掉程序 → 把旧目录改名（如 `VisionForge.old.20261110`）→ 解压新包 → 把旧的 `config.json`、`projects`、`logs`、`run` 拷回新目录。

回滚同理，反着做。**动手前先把 `projects` 备份一份**，程序本体可再下，片子没了要重跑。

---

## 原理（为什么这么做）

### 为什么 Key 不放在程序目录

程序目录会被整体替换、也可能被拷来拷去。Key 放 `%APPDATA%` 后，便携包分享出去不会把密钥一起带走；保存时程序还会用 `icacls` 把文件权限收窄到当前用户。

### 为什么默认端口会漂移

`8765` 被占用时程序不会硬报错，而是往后找空端口。好处是同时开两个版本不会打架，代价是浏览器版需要看启动日志确认实际端口。桌面窗口不关心端口，它自己知道。

### 为什么每一步都要落盘

`project.json` 是唯一事实来源：镜头状态（`pending / keyframe / rendered / voiced / failed`）、提示词、成本都写在里面。所以崩溃后重开能接着跑，单镜重拍只影响那一镜，不会重烧整片的 token 和额度。

### 为什么 first-run 要自动配置

不同机器的编码器差别很大：N 卡有 `nvenc`、Intel 核显有 `qsv`、AMD 有 `amf`。选错会让导出慢几倍甚至报错。自动探测 + 一次最小 `drawtext` 自检，能避免"装好就能用，但导出莫名失败"。

## 常见问题

**双击没反应**：先看 `logs\runtime.log`；多半是 WebView2 缺失，用 `--browser` 能绕过。

**浏览器打开提示 401**：`/api/*` 需要 token。直接访问 `http://127.0.0.1:8765/` 让服务端注入，或从 `run/token` 取值加 `X-VF-Token` 头。

**杀软报警**：PyInstaller 打包的 exe 常被误报，加白名单即可；也可以直接用源码运行。
