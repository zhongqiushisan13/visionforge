# VisionForge 维基

> 这是一套「先做事、再讲理」的文档：每页先给操作步骤，再用一小节解释*为什么这么做*。赶时间只看操作，想调优或排错再看原理。

当前版本：**v1.2.2** · 界面 9 种语言 · 编剧模型 11 个通道

---

## 先选一条路线

| 你的情况 | 推荐路线 | 需要准备 |
|---|---|---|
| 想尽快出一条片子 | 云端剧本 + 云端镜头 | 一个模型 Key（DeepSeek 或 Claude 最稳） |
| 不想花钱、能等 | 本地 Ollama 写剧本 + 本地 ComfyUI/H3 出片 | 显卡 ≥ 8G，模型文件若干 |
| 只想验证流程 | MOCK 模式 | 什么都不用 |

三条路线可以混搭，缺哪环就降级哪环，不会整条断掉。

## 一句话原理

> 界面只跟本机的 FastAPI 说话；后端把「你的需求」翻译成厂商的 HTTP 请求，把长任务拆成「提交—轮询—下载」，每一步结果落盘到 `project.json`，所以随时能停、能续、能单镜重拍。

详细展开在 [原理速查](09-原理速查.md)。

## 约定

- 文中 `%APPDATA%\VisionForge\` 指 Windows 用户配置目录（macOS/Linux 为 `~/.config/visionforge/`）。
- `D:\VisionForge\` 指便携包解压目录，换成你自己的路径即可。
- 命令里的 `python` 指 3.10+；打包版不需要装 Python。
