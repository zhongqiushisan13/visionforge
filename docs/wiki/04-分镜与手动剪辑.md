# 分镜与手动剪辑

> 分镜页决定「拍什么」，剪辑页决定「怎么拼」。两者互不覆盖：改剪辑不会重跑模型。

## 操作

### 分镜页

每个镜头卡片上能做的事：

| 按钮 | 作用 | 会不会重跑模型 |
|---|---|---|
| 预览 | 播放这一镜的视频 | 否 |
| 编辑 | 跳到剪辑页并选中它 | 否 |
| 重拍 | 写意见，改写提示词后重跑 | **会**（关键帧 + 镜头） |
| 停用 | 不进成片，文件保留 | 否 |

工具栏四个动作：

- **出关键帧**：只补没有首帧的镜头
- **生成镜头**：只补没有视频的镜头
- **生成配音**：按当前台词重新配音
- **全量渲染**：三步串起来跑

### 剪辑页

左边是时间线，右边是检查器。时间线支持拖拽排序，点块选中后在右侧改参数。

#### 片段

- **时长**：1~15 秒。改短了不会重跑视频，只是截取；改长了超过源素材会定格尾帧
- **入点 trim**：从第几秒开始用。**只影响成片，不改源文件**
- **分割**：在第 N 秒切成两条镜头，方便分别变速或加转场

#### 变速与翻转

- 速度：0.25× ~ 4×，常用 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2
- 镜像、倒放：各一个开关

#### 转场（与上一镜之间）

内置 11 种：硬切、淡入淡出、叠化、左/右擦除、上/下滑动、推近、黑场、白场、圆形展开。

选「硬切」时转场时长输入框会置灰——硬切没有时长概念。

#### 调色

滤镜预设：原片、电影青橙、黑白、复古胶片、冷调、暖调、高饱和。

再用四个滑杆微调：亮度、对比度、饱和度、色温。预设优先，滑杆叠加在预设之上。

#### 文字层

给这一镜叠加一行文字：内容、位置（上/中/下）、字号（0 = 按分辨率自动）。

#### 声音与字幕

- 音量：0 ~ 2，1 为原始
- 字幕：烧进画面的文字
- 台词 / 旁白：用于配音，也作为字幕默认值

#### 一句话改剪辑

时间线上方有个输入框，可以写：

```
全部调成黑白 · 第2镜1.2倍速 · 加叠化转场
```

有 LLM 时由模型解析成结构化指令；没有 Key 时用本地规则匹配常见说法。解析结果会直接改镜头参数并提示「已应用 / 没听懂」。

### 素材替换与导入

- **换素材**（单镜）：用自己的 mp4 替换这一镜的视频
- **导入素材**（时间线）：追加一条新镜头

导入的视频会读取真实时长，自动更新镜头时长。

### BGM

「成片」页右栏上传，支持 mp3 / wav / m4a。合成时按 `VF_BGM_VOLUME`（默认 0.18）压到底噪位置。

## 原理（为什么这么做）

### 为什么 trim 不改源文件

剪辑参数（入点、速度、转场、调色）都写在 `project.json` 里，合成时才通过 ffmpeg 的 `filtergraph` 应用。

好处：反复调不用重跑模型、不占额外磁盘、随时能改回去。代价：每次合成都要重新编码一遍。

### 速度变化怎么影响成片

`setpts` 改视频时间戳，`atempo` 改音频速度。1.25× 会让这一镜在成片里变短 20%，所以时间线总时长会跟着变。变速超过 2× 时音调容易失真，atempo 会串联多级来减轻。

### 转场是怎么实现的

两个镜头之间用 `xfade`（或 `fade`）混合若干帧，时长由「转场时长」决定。注意：

- 转场会**占用重叠时间**，成片总长会比素材总长略短
- 第一镜没有「上一镜」，所以它的转场设置不生效
- 硬切不产生重叠，总长严格等于各镜之和

### 调色为什么分预设和滑杆

预设是一组固定的 `eq` / `colorbalance` 参数，一次到位；滑杆是在预设结果上再乘系数。先选风格再微调，比从零调四个数值更容易出效果一致的一组镜头。

### 字幕为什么是「烧录 + SRT」两份

烧录（ASS 滤镜）保证任何播放器看到的都一样；SRT 方便二次剪辑或上传平台。字体用系统字体，缺字会变方框——中文机器建议保持「Microsoft YaHei」。

### 响度归一是什么

不同来源的配音、BGM 音量差异很大，直接混会忽大忽小。合成时跑一次 `loudnorm`，把整体响度拉到播出常用区间，再输出。这一步会让「听起来专业」的程度明显提升。

### 一句话改剪辑为什么有的听得懂有的听不懂

LLM 路径会把自然语言翻译成 JSON 指令（`{"op":"speed","shot":"S02","value":1.2}`），表达越具体越准。本地规则路径只覆盖常见模式：全部滤镜、指定镜头变速、加转场。没配 Key 时别指望它理解「让第三镜更有呼吸感」这种话。

## 常见问题

**改了时长但画面卡住**：源素材比设定时长短，尾部会定格。要么调回原时长，要么换更长的素材。

**转场后总时长变短了**：正常，重叠时间被吃掉了。

**字幕是方框**：字体缺中文。设置里换 `Microsoft YaHei` 或 `Noto Sans CJK`。

**倒放后没有声音**：倒放只处理视频流，音频仍是正向；需要的话先静音再用 BGM 铺。
